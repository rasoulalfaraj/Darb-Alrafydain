# درب الرافدين

## الخرائط والبحث

- يعرض **OpenStreetMap** الطرق والأماكن المتوفرة في بياناته داخل التطبيق، ويستخدم **Photon** للبحث داخل العراق. اكتب اسم شارع أو مكان واضغط «بحث في OpenStreetMap». تظهر النتائج في تبويب الأماكن ويمكن عرضها على الخريطة.
- يعرض **Google Maps** الطرق والأماكن داخل التطبيق بعد تفعيل المفتاح. زر «فتح البحث في Google Maps» يفتح النتائج في تطبيق Google Maps أو في المتصفح.
- يوقف وضع عدم الاتصال طلبات الخرائط والبحث المباشر، ويعرض خريطة العراق المحلية والأماكن المضمّنة في التطبيق.
- تغطية الطرق والأماكن تعتمد على بيانات كل مصدر. عرض الطرق والبحث المباشر لا يغيّران طريقة حساب المسارات المحلية الحالية.

## تفعيل خريطة Google داخل التطبيق

1. فعّل **Maps SDK for Android** والفوترة في مشروع Google Cloud.
2. اضبط قيود مفتاح Android لمعرّف الحزمة `com.aistudio.iraqnav.darb` وبصمة SHA-1 لشهادة النسخة التي ستثبّتها. يولّد سير عمل GitHub الحالي شهادات جديدة عند كل تشغيل. استخدم شهادة ثابتة للنسخ التي تعتمد على مفتاح مقيّد.
3. ضع المفتاح في `MAPS_API_KEY` ضمن ملف `.env` للبناء المحلي أو ضمن GitHub Actions Secrets للبناء الآلي.

يعمل OpenStreetMap بدون مفتاح Google. يستخدم التطبيق خوادم البلاطات العامة لـ OpenStreetMap وخدمة Photon العامة للطلبات التفاعلية. للتوزيع واسع النطاق استخدم استضافة أو مزوّداً مخصصاً يتناسب مع حجم الاستخدام.
